# First verified arithmetic milestone

Historical snapshot. The later [classifier milestone](classifier_results.md)
adds verified held-out inference; the unfinished items below describe this
earlier source revision.

[CI run 40445230045](https://github.com/jrmywm/FlexMAC/actions/runs/40445230045)
at source `d1e496086930fc20123c9a12a9af1c124f0b1e2e` passed all steps.

## Functional evidence

- Eight independent Python arithmetic tests passed.
- All 65,536 operand pairs in INT8 mode and all 65,536 packed operand pairs in
  dual-INT4 mode matched the mathematical oracle. Both configurable cores and
  the corresponding fixed baseline were checked.
- Each stream implementation completed 172 oracle-checked frames. Both returned
  identical results and cycle behavior, including the two long overflow frames.
- Reset canceled a partial accumulation and a stalled result in each engine.
- Input gaps with invalid last flags, changes to mode after command acceptance,
  output stalls, and invalid output masking were checked.
- A temporary version that incorrectly made the INT4 low lane unsigned compiled
  successfully, then failed the product assertion as expected.

These are exhaustive combinational checks and sampled sequential tests. They
are not a formal proof of every possible stream/reset sequence.

## Generic synthesis: sharing does not win this first comparison

Yosys 0.33, flattened `synth -noabc`, identical flow:

| Design | Generic cells | Register cells |
| --- | ---: | ---: |
| Shared configurable product | 732 | 0 |
| Separate-unit mux product | 650 | 0 |
| Fixed INT8 product | 424 | 0 |
| Fixed dual-INT4 product sum | 255 | 0 |
| Shared configurable stream | 1,094 | 36 |
| Separate-unit mux stream | 1,014 | 36 |

The shared product is about 12.6% larger by generic-cell count; its stream engine
is about 7.9% larger. These counts do not establish standard-cell area, power,
or achievable frequency. The fixed cores support different operations and are
not runtime-equivalent replacements for the configurable designs.

The shared core genuinely reuses partial products, but dynamic low-lane signed
interpretation, cross-term isolation, and reconstruction need extra logic.
This motivates inspecting mapped cost rather than assuming that reuse saves
area. The exact source of the count difference has not yet been decomposed.
